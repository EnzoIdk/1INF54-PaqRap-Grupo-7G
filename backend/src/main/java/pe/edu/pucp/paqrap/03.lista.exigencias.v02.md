# **1\. Introducción** {#1.-introducción}

El presente documento tiene como propósito definir la versión final y unificada de la Lista de Exigencias para la solución informática propuesta para la empresa PaqRap. Esta lista establece de manera estructurada y detallada los requisitos funcionales y no funcionales que debe cumplir el sistema para asegurar la correcta gestión de pedidos, planificación de rutas, resolución de escenarios de simulación y monitoreo visual.
